# One-Line Roast: The Gadget You Use Every Day

A single original line roasting the gadget I wear every day — my smartwatch, which calmly tells me to breathe and then panics when my own heart rate spikes from reading its notification.

`main.ts` writes the roast line deterministically to `entry.txt` (one line, well under 200 characters).
